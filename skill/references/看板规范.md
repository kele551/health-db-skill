- **版式与字体口径（2026-11-23 用户连提「字体不够规范」「空白处太多」后定）**：
  - 字号**一律 rem 不用 px**（`.75/.875/1/.25/1.5rem` = 12/14/16/20/24），`<head>` 保留 `<meta name="text-scale" content="scale">`，**禁止给 `:root` / `html` 设 font-size** —— 这样手机系统「字体放大」才生效（modern-web-guidance 判据）；字体栈统一为 `"Noto Sans SC","Noto Sans CJK SC",Manrope,Geist,"Segoe UI","Microsoft YaHei",system-ui,sans-serif`（**总览与就诊摘要两页必须同一套栈**；摘要页的 `--serif` 变量以前是宋体、也已换掉，同样用它）。
  - **字体最终口径（2026-11-23 用户三轮截图后定死：就这一版，别再自己换族）**：中间试过等线（DengXian）和微软雅黑，用户看过真图后仍判「这些都不是一个字体」，最后原话「之前都改对了，怎么又改了」「我要这个版本的字体」——就是 `"Noto Sans SC"` 打头这套栈。**不要再因为"看着偏粗/偏细"去换字体族**，用户要的稳定观感比字重微调重要。踩坑记录：① 必须 `"Noto Sans SC"` 打头，否则西文数字会落到栈尾 `Segoe UI`，中文与数字分族；② 用户说「不是一种字体」时先查两件事——有没有**未定义的 CSS 变量**（如旧 `--song` 静默回落成衬线）、数字是不是**单独 600/700 字重 + 强调色**（字重差也会被读成另一种字）；③ 改字体前造同一段「中文＋数字＋单位」对照页截图比族，别只看字体名。
  - 行要紧凑：`.row` 六列 `minmax(170px,1.3fr) 96px 132px minmax(132px,1.15fr) 64px 84px`、行内 padding 8px；参考文字截 34 字防折行把行撑高；`svg.bar`/`svg.spk` **必须写死宽高（132×30 / 74×30）**，否则窄屏被网格拉宽、坐标里的 8px 日期字会被放大成 30px；`.cols`/`.quick` 加 `align-items:start`，卡片按内容高度，别等高拉伸留白。
  - 窄屏（<760px）行布局是 `"nm val badge" / "sp1 sp1 sp2"` 两行式：名称-值-徽章一行、参考条在左趋势在右一行，别用三行式（会多出一半空白）。
