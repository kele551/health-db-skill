# 使用说明

> 这份是操作手册；项目介绍与快速开始见根目录 `README.md`。

## 0. 需要什么

- Python 3.10+（只用标准库；OCR 另需 `onnxruntime`）
- 一个自己的健康数据目录（默认 `data/`）
- 不需要数据库服务、不需要联网、不需要账号

## 1. 安装

```bash
git clone https://github.com/kele551/health-db-skill.git
cd health-db-skill
python install.py          # 可选：把 skill/ 装进 ~/.claude/skills/health-db
```

直接用脚本，不装技能也可以——所有命令都在 `tools/` 下。

## 2. 建库

```bash
python tools/健康库.py init data/医疗与运动健康数据库.db "你的名字"
```

- 建出 25 张标准表：`bp_glu`（血压血糖）、`daily`（步数睡眠心率）、`weight`、`lab`（化验）、`doc`（单据）、`profile`（档案）等。
- 姓名只写进 `meta` 与 `profile`，代码里不写死任何人。
- 已有库时拒绝覆盖；确实要重建加 `--overwrite` 参数需自行确认。

**一人一库**：给别人建就换一个路径，然后：

```bash
# Linux / macOS
export HEALTH_DB=/path/to/他的库.db
# Windows PowerShell
$env:HEALTH_DB = "D:\他的健康数据\他的库.db"
```

## 3. 指标字典

```bash
python tools/指标字典导入.py          # 写入（会先备份 .db）
python tools/指标字典导入.py --check  # 只比对
python tools/指标字典导入.py --export # 反向导出 JSON
```

字典在 `data/指标字典.json`：指标 key、中文名、单位、LOINC、来自哪张表哪一列、参考区间。加指标改这份 JSON，再导入。

## 4. 录入

### 4.1 一句话

```bash
python tools/健康文字录入.py --text "今天早上八点血压128/82，心率76"
python tools/健康文字录入.py --text "早餐后血糖9.8"
python tools/健康文字录入.py --file 语音转写.txt      # 一行一条
```

支持的说法：血压、血糖（可带时点：空腹/早餐后/睡前）、心率、体重、步数、睡眠。认不出就原样报「这句没认出来」，不会瞎猜。

### 4.2 手机截图

```bash
python tools/健康截图入库.py --file "截图.png" --no-cloud
python tools/健康截图入库.py --dry-run --file "截图.png"   # 只看识别结果
python tools/健康截图入库.py --selftest                     # 用内置样例验证解析
```

- 支持华为运动健康、三诺健康等长截图；超长图自动切片。
- 血压 / 血糖 / 日指标 / 体重四类解析器都会跑一遍（长截图常是混合页），按内容去重写库。
- 认不准的行进「待确认」，不写库。

### 4.3 化验单

```bash
python tools/化验单入库.py --file "化验单.png"
python tools/化验单入库.py --file "化验单.png" --dry-run
python tools/化验单入库.py --date 2026-11-15 --file "化验单.png"   # 图上没日期时手填
```

写入 `lab` 表：日期、类别、项目、英文缩写、结果、单位、参考区间、来源文件。同日期同项目自动去重。

### 4.4 处方 / 检查单 / 缴费单

```bash
python tools/单据识别.py --file "处方.png"
python tools/单据识别.py --text "..." --type 处方
```

自动判类型后追加到对应表；`--dry-run` 只预览。查重：

```bash
python tools/单据台账.py check "2026-11-15"
python tools/单据台账.py check "氨氯地平"
python tools/单据台账.py build
```

### 4.5 新的一类指标

```bash
python tools/健康指标扩展.py list
python tools/健康指标扩展.py add --category 血氧 --value 96 --unit % --ref "95–100"
python tools/健康指标扩展.py add --item UA --label 尿酸 --unit umol/L --ref "208–428" --date 2026-11-03 --value 480.6
```

写进 `ext_metric` 表；看板自动多出一行与时间线节点。

## 5. 看板与周报

```bash
python tools/健康档案看板.py --out data/看板.html
python tools/健康周报.py --out data/周报.html
python tools/健康周报.py --end 2026-11-18 --out data/周报.html
```

- 看板：按身体系统分组，每行「最新值 + 参考区间标尺 + 三色提示」；顶部「需要跟医生说的」只列越界项。
- 周报：默认取库里最近 7 天；数据没跟上今天时按最后一条数据往回数，不硬凑空日子。
- 两页都是单文件 HTML，内嵌 CSS 与自写 SVG，无外链，断网可看。

改版式后核对只改了数据、没改版：

```bash
python tools/看板一致性校验.py data/看板-baseline.html data/看板.html
```

## 6. FHIR 导出

```bash
python tools/导出FHIR.py --out data/fhir
python tools/导出FHIR.py --version r5 --out data/fhir-r5
python tools/健康数据库.py fhir --out data/fhir.json
```

六类资源：Patient / Observation / Condition / MedicationStatement / DiagnosticReport / Encounter。映射表在 `overview/fhir映射.json`。

## 7. 加指标 / 加分组 / 加表

| 要加什么 | 改哪里 |
|---|---|
| 一个化验指标 | `overview/schema.json` 的 `indicators`，再跑 `指标字典导入.py` |
| 看板一行 / 分组顺序 | `overview/看板定义.json` 的 `分组` → `行` |
| 一张新表 | `python tools/健康库.py add-table <表> <列:类型,...>` |
| 一列新字段 | `python tools/健康库.py add-column <表> <列> <类型>` |
| 目标区间 | `tools/健康目标口径.py`（按年龄分层，附指南出处） |

## 8. 备份与迁移

- 备份＝复制 `data/医疗与运动健康数据库.db`（单文件，含全部数据）。
- 迁移＝把 `.db` 拷到新机器，设 `HEALTH_DB` 指过去即可，代码不用改。
- 想自动备份就用自己的网盘同步工具盯 `data/`；本工具不内置任何上传。

## 9. 故障排查

| 现象 | 原因与处理 |
|---|---|
| `ModuleNotFoundError: onnxruntime` | OCR 没装：`pip install onnxruntime`；或设 `HEALTH_OCR_PY` 指向装好的解释器 |
| 看板 0 组 0 行 | 库是空的，先录一条数据，或 `python demo/make_demo.py` 看演示 |
| 页面没更新 | 页面是按库生成的，重新跑一次看板脚本；清 `.医疗看板缓存.json` 可强制重算 |
| 库路径不对 | 设 `HEALTH_DB`，或用 `--db` 参数；脚本只读你指的那一份 |
| 中文乱码（Windows） | 终端先 `chcp 65001`，命令行加 `-X utf8` |

## 10. 边界

- 只做规则提示，不做诊断；异常项请找医生。
- 识别不出、图上没日期、字段缺失，一律留空或「待确认」，不猜不补。
- 演示数据为虚构；仓库与代码里不含任何真人的姓名、医院、病案号。
